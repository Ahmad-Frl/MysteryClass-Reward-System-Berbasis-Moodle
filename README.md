MYSTERYCLASS REWARD SYSTEM: Implementasi Conditional Activity dan Point Exchange Berbasis Moodle

## ✨ Fitur Unggulan
<table>
<tr>
<td width="50%">

### 🏆 Sistem Poin & Level
- Poin otomatis dari setiap aktivitas Moodle
- Sistem leveling dengan threshold dinamis
- Bonus poin untuk streak harian
- Multiplier poin berdasarkan difficulty soal

### 🎖️ Badge & Achievement
- 50+ badge eksklusif yang bisa di-unlock
- Achievement tersembunyi (*mystery achievements*)
- Rare badge untuk milestone khusus
- Export badge ke Open Badge format

</td>
<td width="50%">

### 📊 Leaderboard Real-time
- Ranking per kelas, per mata pelajaran, global
- Weekly/Monthly/All-time leaderboard
- Anti-cheat detection system
- Anonymous mode untuk privasi siswa

### 🎁 Reward Store
- Tukar poin dengan reward nyata
- Integrasi dengan sistem kampus
- Flash sale reward dengan countdown timer
- Wishlist & notifikasi restock
